## ✨ Key Features
*   **Instant Media Scanning:** Drag and drop or click to upload your image/video payload (`.JPG`, `.PNG`, `.WEBP , .MP4`).
*   **Hive Neural Verification:** Connects to decentralized neural nodes to decrypt payload data and analyze visual structures.
*   **System Verdicts:** Get an immediate, definitive answer on whether an image/video is real or AI-generated.
*   **Probability Matrix:** View the exact confidence levels comparing human origin vs. artificial/altered origin.
*   **Forensic Signal Signatures:** Analyzes deep pixel-level and cryptographic signatures to detect manipulation invisible to the human eye.
*   **Decoded Temporal Frames:** Advanced structural breakdowns of the uploaded media.

## ⚙️ How It Works
1.  **Initialize Scan:** The user uploads a questionable image/video via the secure dropzone.
2.  **Payload Decryption:** The system ingests the file and connects to the neural nodes for deep analysis.
3.  **Forensic Breakdown:** The image/video is tested for known AI generation patterns, manipulation artifacts, and structural inconsistencies.
4.  **Verdict Delivery:** TruthLense outputs a transparent probability matrix, giving the user a clear percentage of the image/video/video's authenticity.
